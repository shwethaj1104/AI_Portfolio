# Project 01 — demo videos

Put the RAG chatbot demo video here, for example `demo.mp4`.
Then edit project_01 in `src/data/sitecore.ts`:

    videoUrl: '/projects/project_01/video/demo.mp4',

The project-level URL applies to every carousel image unless the image has its own `videoUrl`. Videos open in a new tab. The path stays empty until your real video is available, so no broken video link is shown.
